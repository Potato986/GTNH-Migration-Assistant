# GTNH 迁移助手

GTNH 迁移助手是一款 Windows 便携工具。更新 GT New Horizons 整合包时，你可以把旧实例中的存档、地图标记、快捷键和资源包按需迁移到新实例。

## 迁移准备

需要将最新版本成功安装到游戏内并成功启动，确保自己的启动器内有两个完整的整合包

### 使用方法

1. 关闭游戏，在[最新发行版](https://github.com/Potato986/GTNH-Migration-Assistant/releases/latest)下载 `.exe` 文件，双击运行，无需安装。
2. 先选择旧实例作为来源，再选择新实例作为目标。可以选择 Prism 实例目录或其中的 `.minecraft` 目录。
3. 在「可勾选迁移」中选好内容，点击「预览迁移」，核对清单后确认。完成后，用启动器打开新实例即可。

如果新实例已有同名存档，可以选择「另存世界」保留两份。想补回缺少的截图或地图文件，可在「目标已有」中双击对应目录查看差异。

v0.2 会自动发现常见启动器目录中的 GTNH 实例，也支持搜索本地磁盘。目标还没有生成快捷键设置时，第一次迁移即可勾选旧实例中的设置。

需要汉化时，点击「选择汉化版本」，列表会立即显示已有版本目录，可以搜索版本号或文件名。选中后点击「查看并安装」，可直接下载到目标实例，或加入本次迁移清单。目录可刷新，并在 GitHub API 限流时尝试从发行网页读取。查询或下载可取消，网络异常时提供[手动下载页](https://github.com/Kiwi233/Translation-of-GTNH/releases)。

请选择与目标整合包相符的汉化。旧版完整包（complete）还会覆盖 scripts，具体使用要求以汉化包内说明为准。覆盖前的文件保存在目标目录的 `.gtnh-translation-backup-*` 文件夹。
